JAWS Screen Reader Concepts and Selected Commands

  • On laptops the JAWS key is the Caps Lock key on desktops it is the Insert key.
  • Use the Shift key moves to previous item.
Keyboard Command Description
JAWS+Control+Z
  • Toggle on/off virtual JAWS cursor for reading web pages.
  • Must be in virtual mode for the following commands to work.
JAWS+F5 Form control List
JAWS+F6 Heading List
JAWS+F7 Links List
JAWS+Control+B Button List
JAWS+Control+G Graphics/images List
JAWS+Control+R Landmark Regions List
JAWS+Control+T Table List
JAWS+T Read page title
B Next button
F Next form control
G Next graphic/image
H Next heading
1-6 Next heading at the corresponding level
L Next list
R Next landmark region
T Next table

Feature Overview

  • In virtual you can move sequentially through the headings on a page or view a list of headings.
  • When navigating a web page JAWS announces heading information when the virtual or PC cursor is on a heading.
